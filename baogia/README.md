# Báo giá triển lãm quốc tế

Bảng giá Gói 1 / 2 / 3 — không sửa theme. Dùng sau buổi tư vấn tại studio.

Không gắn ads vào URL này. Không gửi giá ở tin nhắn đầu.

## Đưa lên WordPress

1. WP Admin → Pages → Add New
2. Title: `Báo giá triển lãm quốc tế` — slug: `bao-gia`
3. Góc phải editor → ⋮ → **Code editor**
4. Dán toàn bộ `gutenberg-vi.txt` → Publish
5. Không gắn menu. Custom field tùy chọn: `_ath_gutenberg_migrated` = `1`
6. Bản EN: page mới, title `International exhibition packages`, slug `bao-gia-en`, dán `gutenberg-en.txt`

URL sẽ là `https://arttutorhanoi.com/bao-gia/` (và `/bao-gia-en/`).

Nếu chỉ dùng in/gửi file: mở `index.html` (VN) hoặc `en.html` → **In A4**.
